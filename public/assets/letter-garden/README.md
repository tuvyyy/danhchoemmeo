# Chapter 03 garden background

`garden-dusk.webp` is the existing project artwork `src/assets/garden/moonlit-garden.png`, converted to WebP quality 88 (240,936 bytes). No new generated image or external image source was added.

The scene grades this background with dark green overlays. The original animated lilies and tulips remain independent, confined to the bottom band requested by the user. Their saturation, brightness, scale and grouping are tuned to the same dusk lighting. The letter stays ivory and readable.
