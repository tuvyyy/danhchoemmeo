# Flower chapter

The active chapter is src/sections/FlowersSection.tsx.

- FlowerBloomCanvas.tsx draws the 60 transparent WebP lily frames from public/assets/flowers/lily-bloom-hd/. The URL sequence is generated by src/lib/assets/preloadBloomSequence.ts.
- TulipBloom.tsx loads all six WebP frames from public/assets/flowers/tulip-sequence-v3/ and reuses them for the flower color variants.
- MeadowLayer uses public/assets/flowers/nature/grass-airy-tall.png and grass-back-strip.png.
- FlowerAtmosphere.tsx and FlowerAtmosphere.css provide the current garden atmosphere.
- The chapter waits for the flower sequences to complete before unlocking the next step, and supports reduced motion.

Keep every frame in the two active sequences: the paths are generated dynamically, so individual filenames may not appear in a text search.

The old PNG slideshow, unused video fallback, static flower components, unused image packs, and their generated screenshots were removed from the working project during cleanup on 2026-09-25.

Run npm run typecheck and npm run build to verify the source. Browser test scripts create their captures under docs/screenshots/, which is ignored by Git.
