# Envelope Voucher Asset Pack

Included transparent PNG assets for building the romantic burgundy envelope voucher scene.

Suggested layer order (back to front):
1. `01_envelope_base_closed.png` — base envelope body/background.
2. `04_envelope_inner_liner.png` — ivory inner lining.
3. `06_letter_note.png` — left paper note.
4. `07_voucher_01_food.png` to `10_voucher_04_anywhere.png` — fan the vouchers on the right.
5. `03_envelope_bottom_pocket.png` — place in front so it covers the lower portion of the note/cards.
6. `02_envelope_top_flap.png` — animate as the opening top flap.
7. `05_wax_seal.png` — center near the flap seam.

Recommended animation:
- Start with the envelope visible.
- Open the top flap.
- Lift the letter slightly from the left.
- Slide up vouchers one by one with staggered timing.
- Hover a voucher to raise it slightly and increase shadow.
