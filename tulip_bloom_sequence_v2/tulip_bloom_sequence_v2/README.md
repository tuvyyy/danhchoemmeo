# White Tulip Bloom Sequence v2

This pack is ONLY for the white tulips. It does not include grass.

## Contents
- `webp/`: 7 ordered bloom stages optimized for the website.
- `png/`: original transparent PNG stages.
- `preview_contact_sheet.jpg`: visual order check.
- `manifest.json`: stage order + suggested wave timing.

## Stage order
1. closed
2. bud
3. first open
4. opening
5. half open
6. nearly open
7. full open

## Recommended use
Reuse the SAME 7-stage sequence for every tulip. Do not use each stage as a separate flower.
For each tulip instance vary only x/y, scale, rotation, z-index and start delay.

Suggested final scene:
- 2 pink lilies already present
- 5 white tulips
- tulips bloom in waves, not all at once

Suggested waves:
- Wave 1: main lily
- Wave 2: small lily +700ms
- Wave 3: tulip 1 + tulip 2 +1400ms
- Wave 4: tulip 3 +2050ms
- Wave 5: tulip 4 + tulip 5 +2700ms

Do not rebuild grass or other sections.
