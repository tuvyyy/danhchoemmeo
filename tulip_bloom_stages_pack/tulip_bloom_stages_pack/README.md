# Tulip Bloom Stages Pack

Included:
- tulip_bloom_stages/: 5 staged tulip PNGs for a bloom-by-stage effect
- lily_sequence/: existing 60-frame pink lily sequence (WebP)

Recommended use:
- For tulips: switch stage-by-stage based on scroll progress or chapter timing.
- For lilies: use the 60-frame sequence for the hero bloom.

Suggested thresholds for tulip stages:
- 0.00–0.20 -> stage 01
- 0.20–0.40 -> stage 02
- 0.40–0.60 -> stage 03
- 0.60–0.80 -> stage 04
- 0.80–1.00 -> stage 05
