# Tulip Bloom Sequence V3

Six staged frames of one ivory/white tulip concept, designed to stay recognizably tulip-shaped through the final stage.

## Order
1. `tulip_v3_01_closed`
2. `tulip_v3_02_bud`
3. `tulip_v3_03_opening`
4. `tulip_v3_04_half_open`
5. `tulip_v3_05_nearly_open`
6. `tulip_v3_06_full_open`

Use `webp/` for the website and keep `png/` as source/master assets.

Recommended use: preload the six WebP files once, reuse the same sequence for multiple tulip instances, and stagger each instance with different x/y/scale/rotation/delay. Do not render multiple stages simultaneously.
