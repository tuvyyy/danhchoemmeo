Birthday flower asset pack

Suggested usage:
- lily_frame_01_bud.png ... lily_frame_05_full_bloom.png: use as a bloom sequence for the smaller flower.
- lily_static_alt_full_bloom.png: use as the second flower already in bloom.
- grass_back.png, grass_mid.png, grass_front.png: layer from back to front and animate with different sway speeds.

All files are PNG with transparency.
